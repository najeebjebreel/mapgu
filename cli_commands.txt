# ============================================================
# MAPGU CLI COMMANDS — FULL RUNTIME TRAJECTORY
# ============================================================
# Run order: STEP 1 → STEP 2 → STEP 3 → STEP 4 → STEP 5
# Full runner: python scripts/run_cli_commands.py [--dry-run]
#
# STEP 1  ONE-TIME preparation (writes runtimes.csv into data dirs)
# STEP 2  Baseline / SISA experiments
# STEP 3  k-anonymity / DP experiments  (read prep runtimes from STEP 1)
# STEP 4  CERTIFIED_SP experiments
# STEP 5  Focused sensitivity studies
#
# Conventions:
# - Run-flag order: identity -> scope -> training/model -> performance -> method-specific -> MIA
# - Main privacy settings: k=30 and epsilon=1
# - CIFAR-10/ResNet-18 fine-tuning study: ft_epochs in {3, 5, 10, 20, 30, 50}
# - Sensitivity studies write under results/sensitivity_studies/<study>/<dataset>/
# - Canonical run flags: --n_repeat 5 and --forget_ratios 0.05
# - ft_epochs=5  num_shards=5  num_slices=10
# - Seed: 7 (default)
# - Add --cifar_download true on first run if CIFAR-10 is not cached.
# - CIFAR-10 supports resnet18 and densenet; examples below use resnet18.
# - rmia_n_ref=8 for all datasets (better variance; CIFAR-10 adds ~3.4h/experiment)
#
# NOTE: Remove --skip-existing on first run so runtimes are measured fresh.
#       Re-add --skip-existing true afterwards to avoid regenerating data.
# ============================================================
